# プレースホルダ変数一覧

各ドキュメントで使う `{{変数名}}` の定義。**テンプレートをコピーしたら最初にここを埋め、一括置換する。**

## 置換手順

```bash
# 例: macOS / Linux
cd devdocs
grep -rl '{{PRODUCT_NAME}}' . | xargs sed -i '' 's/{{PRODUCT_NAME}}/実際の名前/g'

# 未置換の変数が残っていないか確認
grep -rno '{{[A-Z_]*}}' . | sort -u
```

| 変数 | 意味 | 記入例 | 本プロジェクトの値 |
|---|---|---|---|
| `{{PRODUCT_NAME}}` | プロダクト名（表示名） | 様式2 調達仕様書システム | |
| `{{REPO_NAME}}` | リポジトリ名／パッケージスコープ | procspec | |
| `{{CLIENT_NAME}}` | 発注元・依頼部門 | 調達部門 / VMO | |
| `{{TARGET_USERS}}` | 主たる利用者 | 事業部門の仕様書作成者 | |
| `{{PLAN_LABELS}}` | 段階プランの呼称 | A（ミニマム）/ B（スタンダード）/ C（フルスペック） | |
| `{{CURRENT_PLAN}}` | 今回のスコープにあたるプラン | A | |
| `{{PHASE_LABELS}}` | フェーズ区分の呼称 | P0 立上げ・設計 / P1 基盤 / P2 機能 / P3 仕上げ | |
| `{{FE_FRAMEWORK}}` | フロントエンド基盤 | Next.js (React) | |

| `{{DATABASE}}` | データベース | PostgreSQL | |

## 汎用プレースホルダ（一括置換の対象外）

以下は文脈ごとに中身が変わるため、**一括置換ではなく手で埋める**。

| 記法 | 意味 |
|---|---|
| `{{N}}` | 任意の数値（工数・秒数・件数など） |
| `{{}}` | その場で埋める自由記述 |
| `{{日本語の説明}}` | 何を書くかの指示。文章に置き換える |

置換漏れの確認時は、上記を除外して検索する:

```bash
grep -rno '{{[A-Z_]\{2,\}}}' . | sort -u
```
