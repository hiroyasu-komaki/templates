# ADR（Architecture Decision Records）

重要な設計判断の記録。**「なぜその選択をしたか」は3ヶ月後に必ず失われる**ため、決定した時点で残す。

## いつADRを書くか

書く:

- 後から変えると高くつく判断（フレームワーク・DB・認証方式・データの持ち方）
- 複数の妥当な選択肢があり、議論して1つを選んだこと
- 一次資料の推奨と異なる選択をしたこと
- 「なぜこうなっているのか」を後から聞かれそうなこと
- **意図的に何かをやらないと決めたこと**（記録が無いと、後で誰かがやってしまう）

書かない:

- 選択肢が実質1つしかなかったこと
- 些細な実装判断 → `_templates/decision-log.md` へ

## 書き方

1. `_templates/adr-template.md` をコピーする
2. `NNNN-短い決定名.md` の形式で保存する（連番・ケバブケース）
3. 下の一覧に追記する
4. **決定した直後に書く。** 後でまとめて書こうとすると、判断理由が失われている

## 決定を覆すとき

既存ADRは**書き換えず、編集もしない。** 新しいADRを起こし、旧ADRのステータスを「置換済み（→ ADR-NNNN）」に変更する。**議論の履歴が残ることに価値がある。**
