## 1. 部品化の判断基準

> 📝 記入ガイド: どういう項目を構造化し、どういう項目を自由記述に残すかの基準を先に決める。基準が無いと、実装者ごとに判断がぶれる。

| 自由記述に残す | 構造化する |
|---|---|
| 本質的に文章でしか表せない内容 | 数値・日付・金額 |
| 例外的・非定型な補足 | 選択肢が列挙できるもの |
| {{}} | 繰り返し構造を持つもの（行テーブル） |
| | 条件付きで詳細を聞くもの（チェック→詳細入力） |

## 4. ガイド文・入力例の見せ方

> 📝 記入ガイド: 説明文をどこにどう出すか。**入力欄に長い例文を常時表示すると圧迫感が出る**ので、置き場所の方針を決める。

| 種別 | 置き場所 | 表示方式 |
|---|---|---|
| セクションの目的説明 | セクション冒頭 | 常時表示・1〜2行 |
| 項目の補足 | 項目直下 | 常時表示・短文 |
| 記入例 | | トグル / ツールチップ / サイドパネル |
| プレースホルダ | 入力欄内 | 短い形式ヒントのみ |
