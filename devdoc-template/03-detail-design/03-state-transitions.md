# 状態遷移設計

- **最終更新**: YYYY-MM-DD

> 📝 記入ガイド: 業務対象が持つステータスと、その遷移を定義する。**遷移可能な組み合わせを表で網羅すること。** 文章で書くと必ず抜けが出て、実装時に「この状態からこれはできるんだっけ」が発生する。
>
> 今回スコープで一部の遷移しか実装しない場合も、**全体の遷移図は先に描く。** 状態の定義だけ先に確保しておけば、後から遷移を足すのは容易だが、状態の定義を後から変えるのはデータ移行を伴う。
>
> ワークフローを持たないシステムでは本ファイルを削除してよい。
